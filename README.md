# 🕷️ 공각기동대 S.A.C. 타치코마(Tachikoma) 페이퍼크래프트 3D 모델 & 인터랙티브 뷰어

본 프로젝트는 애니메이션 **『공각기동대 STAND ALONE COMPLEX - be Human OST』** 음반 부록으로 수록된 **타치코마(Tachikoma) 페이퍼크래프트 전개도(2장)**를 분석하여, 조립이 완성된 형태의 3차원(3D) 다면체 메쉬 모델로 복원하고 웹 브라우저에서 직접 조작 및 다운로드할 수 있도록 구현한 프로젝트입니다.

- 프로젝트: https://jaytwolab.github.io/tachikoma-paper-kr/

---

## 📁 프로젝트 파일 구성

| 파일명 | 설명 | 활용 용도 |
| :--- | :--- | :--- |
| `tachikoma_papercraft_3d.html` | Three.js 기반의 단일 파일 인터랙티브 3D 조립 뷰어 및 실시간 익스포터 | 웹 브라우저에서 3D 회전/확대, 분해 보기, 즉시 파일 추출 |
| `tachikoma_assembled_model.glb` | 색상과 재질(Material)이 포함된 바이너리 glTF 3D 모델 | 웹 3D 뷰어, Blender, Unity, Unreal Engine 등 |
| `tachikoma_assembled_model.obj` | 파츠별로 그룹(`o`, `g`)이 분리된 표준 Wavefront 3D 메쉬 파일 | 범용 3D CAD/모델링 소프트웨어 (Maya, 3ds Max, Rhino 등) |
| `tachikoma_assembled_model.mtl` | `.obj` 파일과 연동되는 타치코마 전용 색상/재질 정의 파일 | `.obj` 임포트 시 색상 자동 적용 |
| `tachikoma_assembled_model.stl` | 단일 메쉬로 병합된 3D 프린팅용 바이너리 STL 모델 | 3D 프린터 슬라이서 소프트웨어 (Cura, PrusaSlicer 등) |
| `tachikoma_3d_model_bundle.zip` | 위의 `.obj`, `.mtl`, `.stl`, `.glb` 파일을 하나로 묶은 압축 아카이브 | 일괄 다운로드 및 보관용 |

## 🧩 전개도 파츠별 3D 모델링 명세

원본 페이퍼크래프트 도면의 **산접기(점선, 山折り)**, **절취선(실선, 切り込み)**, **풀칠 탭(のりしろ)** 구조를 그대로 반영하여 종이모형 특유의 각진 다면체(Low-poly Faceted Cardstock) 조형미를 살렸습니다.

### 1. A 파츠 : 후방 포드 / 콕핏 블록 (Sheet 1)
* **A (후방 포드 본체)**: 수직 팔각 다면체 구조로 접힌 콕핏 블록과 상단 해치 덮개, 전면 모서리에 인쇄된 4쌍의 주황색 경고등 디테일을 재현했습니다.
* **A-1 (좌·우 측면 돔 ×2)**: 10각 꽃잎 형태로 오려 붙여 반구형으로 만드는 은색 측면 센서 돔입니다.
* **A-2 (후방 돔 ×1)**: 포드 후면 하단에 부착되며 중앙에 3개의 핀홀(검은 점)이 인쇄된 반구형 센서 돔입니다.

### 2. B 파츠 : 전면 중앙 동체 및 광학 센서 (Sheet 2)
* **B (전면 동체 및 하부 허브)**: 6갈래 꽃무늬 전개도를 접어 만든 육각 구형 몸통과 하단 중앙에 인쇄된 4구 은색 다리 관절 허브를 포함합니다.
* **B-1 (유탄발사기 포구 및 조준경)**: 동체 정면 중앙에 돌출된 은색 원통형 포신과 상단의 원형 조준경 탭입니다.
* **B-2 · B-3 (상부 센서 마스트)**: 동체 정수리에 수직으로 솟은 왕관 형태의 기저부(`B-3`)와 사각 기둥 센서 포스트(`B-2`)입니다.
* **B-4 (3구 광학 안구 볼 ×3)**: 전면 좌·우 및 상단에 배치된 3개의 은색 반구형 안구로, 각 눈마다 타치코마 특유의 삼각형 핀홀(점 3개)이 구현되어 있습니다.
* **B-5 (허리 연결 조인트)**: 전면 동체(`B`)와 후방 포드(`A`) 사이를 곡선으로 이어주는 청색 허리 칼라 부품입니다.

### 3. C 파츠 : 4족 보행 및 주행 다리 (Sheet 2 - `C 脚` ×4)
* **C-1 ~ C-4 (전방 좌/우, 후방 좌/우 다리)**: 2개의 곡선형 산접기 점선을 따라 유선형으로 휘어지는 청색 다리 외장갑, 다리 안쪽의 하늘색 타원형 패드, 발목의 은색 커버(핀홀 3개 포함) 및 하단 다크그레이 바퀴(Wheel) 포드로 구성됩니다.

### 4. D 파츠 : 양팔 매니퓰레이터 (Sheet 1 - `D 右腕` / `D 左腕`)
* **D 우완(右腕) 및 좌완(左腕)**: 은색 구형 어깨 관절과 청색 팔뚝 장갑, 우완 바깥쪽의 보조 실린더 포드 디테일을 포함합니다.
* **D 선단(先端)**: 부채꼴 은색 전개도를 말아 만든 손목 칼라와 위아래로 마주 보는 2지 집게발 그리퍼(Pincer Claws)입니다.

## 🖥️ 인터랙티브 3D 뷰어 사용 방법 (`tachikoma_papercraft_3d.html`)

별도의 서버나 프로그램 설치 없이 `tachikoma_papercraft_3d.html` 파일을 웹 브라우저(Chrome, Edge, Safari, Firefox 등)에서 바로 열면 실행됩니다.

### 🎮 마우스 및 터치 조작
* **시점 회전 (Orbit)**: 마우스 좌클릭 후 드래그 (모바일: 한 손가락 드래그)
* **화면 이동 (Pan)**: 마우스 우클릭 후 드래그 (모바일: 두 손가락 드래그)
* **확대 / 축소 (Zoom)**: 마우스 휠 스크롤 (모바일: 두 손가락 핀치 줌)

### 🛠️ 뷰어 주요 기능
1. **전개도 분해 보기 (Exploded View 슬라이더)**
   * 좌측 제어판의 슬라이더를 `0%`에서 `100%`로 조절하면 **A, B, C, D 각 부품과 세부 파츠(A-1, A-2, B-1~B-5)**가 조립 방향을 따라 공간상으로 분리되어 어느 부품이 어디에 결합되는지 직관적으로 확인할 수 있습니다.
2. **파츠별 단독 필터링 (상단 탭 바)**
   * 상단 메뉴의 `전체 보기`, `A: 후방 포드`, `B: 전면 동체·눈`, `C: 다리 (×4)`, `D: 양팔 (×2)` 버튼을 클릭하여 원하는 파츠 그룹만 단독으로 표시할 수 있습니다.
3. **종이 접기선 표시 (산접기/골접기)**
   * 종이모형의 다면체 모서리 접기선(Crease Lines)을 켜거나 끌 수 있습니다.
4. **부품 기호 라벨 표시**
   * 각 파츠 위에 전개도 번호(`A`, `B-1`, `C-1`, `D(우완)` 등)를 실시간 3D 플로팅 배지로 표시합니다.
5. **구동 애니메이션 (아이들 모션)**
   * 타치코마 특유의 서스펜션 호흡 모션, 3개 안구의 미세한 회전 스캔, 집게발 흔들기 모션을 켜거나 정지할 수 있습니다.
6. **클라이언트 즉시 다운로드**
   * 우측 하단 패널의 **`.GLB`**, **`.OBJ`**, **`.STL`** 다운로드 버튼을 누르면 현재 브라우저에서 즉시 3D 모델 파일을 생성하여 로컬 PC로 저장합니다.

## 🎨 외부 3D 소프트웨어에서 열기

### 1. Blender (블렌더)에서 열기
* **GLB 사용 시**: `File` ➔ `Import` ➔ `glTF 2.0 (.glb/.gltf)`를 선택하여 `tachikoma_assembled_model.glb`를 불러오면 재질과 색상이 즉시 적용됩니다.
* **OBJ 사용 시**: `tachikoma_assembled_model.obj`와 `tachikoma_assembled_model.mtl`을 **동일한 폴더**에 두고 `File` ➔ `Import` ➔ `Wavefront (.obj)`로 불러오면 파츠별 오브젝트 계층과 색상이 함께 로드됩니다.

### 2. 3D 프린터 슬라이서 (Cura / PrusaSlicer / Bambu Studio)에서 열기
* `tachikoma_assembled_model.stl` 파일을 슬라이서에 드래그 앤 드롭합니다.
* 기본 스케일은 소형 데스크탑 피규어 비율로 설정되어 있으므로, 원하는 출력 크기에 맞춰 슬라이서에서 배율(Scale, 예: `1000%` ~ `2500%`)을 조절하여 출력하세요.
